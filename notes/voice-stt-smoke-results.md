# Локальная проверка STT (Linux, без G2)

Runtime: sherpa-onnx **1.13.0**, CPU, один поток, task=transcribe, tailPaddings=1000. Проверены реальные ONNX-файлы из maintainer HF mirror; SHA-256 всех трёх скачанных файлов совпали с manifest в asr-model.ts. Время ниже — облачный x86 Linux под параллельной нагрузкой сборки, **не задержка Android/G2 и не benchmark для выбора телефона**.

Источники:

* RU: `https://huggingface.co/csukuangfj/sherpa-onnx-nemo-ctc-giga-am-russian-2024-10-24/resolve/main/test_wavs/example.wav`, 11.29 s, 16 kHz mono. Литературная речь, не набор команд.
* EN: `https://huggingface.co/csukuangfj/sherpa-onnx-whisper-base/resolve/bb53ee204431c90d314c1cc08d28d23e5b7927cc/test_wavs/0.wav`; эталон рядом в test_wavs/trans.txt. Приведён к 16 kHz mono.
* Mixed: искусственное объединение первых 4 s RU + первых 4 s EN, один 8-секундный вход. Это стресс-проверка смены языка внутри сегмента, не запись реального двуязычного человека.

| Проверка | Base int8 | Small int8 (сравнение) |
| --- | --- | --- |
| RU, language=ru / пустой auto | Русский текст получен; два повтора base совпали; есть ошибки в окончаниях и отдельных словах | Русский текст получен; ошибок меньше в части фразы, но качество всё ещё не идеальное |
| EN, language=en | Слова совпадают с эталоном после нормализации регистра/пунктуации | Не измерялось |
| Mixed RU→EN, ru и auto | Английский хвост пропущен — проверка **не пройдена** | Английский хвост также пропущен — проверка **не пройдена** |
| Создание recognizer | 1.41–4.78 s | 3.33–5.09 s |
| RU decode 11.29 s | 5.61–14.79 s, включая первый cold inference | 16.52–16.82 s |
| Повтор на уже созданном base | Конструктор не вызывается; отдельный OfflineStream, стабильный результат | Два входа на одном экземпляре выполнены |

Multilingual small проверялся из `csukuangfj/sherpa-onnx-whisper-small`, revision `8f3c18b358db4d1f2fc1eae49d75cd20989e4309`: encoder int8 SHA-256 `4cbe7b22fa9026b843b60a68640c747de05bafb1a11b57edc0e66c232d9f33a9`, decoder `acad50b5c782696e91b55914cc5ab4f756f1532f76e22aa6fc615f39fb69a8ee`, tokens совпадают с base. Размер ~375 MB против ~161 MB у base. Small не включён в приложение: этот конкретный проблемный случай он не исправил, а вычислительная нагрузка выше. Base оставлен начальным мобильным вариантом, с явным ограничением по смешанной речи.

GigaAM имеет sherpa-onnx экспорты v2/v3 и может быть следующим кандидатом для специализированного русского режима без нового inference runtime. Он не заменяет многоязычный Whisper для английского/автоопределения. GigaAM в этой работе не запускался; превосходство на командах G2 не заявляется.

Вывод: доказана совместимость модели с закреплённым runtime и локальное распознавание RU/EN, но **качественное распознавание русских команд и смешанной речи на G2 не сертифицировано**. Проверка mixed выявила реальное ограничение. Нужен device-корпус из voice-interface-validation.md; при неприемлемом результате этот критерий остаётся открытым. Эти результаты нельзя заменять утверждением «все критерии готовности выполнены».
