# Проверка голосового интерфейса

## Настройки

Android: Settings → Assistant → Bridge transport → WSS, Bridge host → `agent.example.com`, Bridge port → пусто (443), Bridge token → прежний секрет. Для WS автоматически используется 8790. Явно сохранённые порты, в том числе 8790 на старых установках, сохраняются при переключении схемы: очистите поле для автоматического выбора. Хост вводится без схемы/пути; IPv6 — в квадратных скобках. TLS использует системное доверие Android; неправильный сертификат/имя/цепочка блокируют соединение без перехода на WS. Конфигурация Nginx: `notes/nginx-agent-bridge.conf`. Bridge и OpenClaw Gateway не публиковать: слушать loopback, закрыть прямые порты firewall, оставить авторизацию token.

Android: Settings → Voice → скачать `Whisper (multilingual, base)` (~161 MB), выбрать `On-device (Whisper multilingual)`, Local Whisper language → Русский / English / Auto-detect. Существующие Moonshine и Whisper English сохранены. Многоязычная модель: экспорт sherpa-onnx, `base` int8, revision `bb53ee204431c90d314c1cc08d28d23e5b7927cc`; каждый файл проверяется существующим downloader по SHA-256. Используется тот же runtime sherpa-onnx 1.13.0, task=transcribe, пустой language означает определение языка. Автоопределение выполняется на сегмент, а не на каждое слово; качество переключения языков внутри фразы требует проверки.

## Воспроизводимое сравнение на Android + G2

В этой облачной среде нет телефона/G2. Таблица реального устройства пока не заполнена; нельзя считать задержку 2–3 s измеренной или устранённой на оборудовании.

1. Создать отдельный checkout базовой версии `b353483ac2a7f4b0f1cc69613bbebd48cd3163d7`. Применить к нему **только** `notes/voice-baseline-timing.patch` из новой версии. Патч добавляет те же монотонные метки, убирает текст из STT-логов, сохраняя исходный порядок STT → mic и освобождение STT после сессии. Собрать APK.
2. На одном телефоне, одной прошивке G2 и одинаковой модели выполнить холодный запуск и ≥20 повторов Hey Even с одинаковой фразой. Не включать сохранение аудио в Developer settings. Дать первому запуску модели закончиться, затем говорить; отдельно проверить речь сразу после wake word. Проверить память после 50 сессий.
3. Сохранить только нужные теги: `adb logcat -c`, затем `adb logcat -v brief FaceclawVoice:I '*:S' > before.log`. Остановить запись Ctrl+C. Эти метки содержат только стадии, идентификатор сессии и время `elapsedRealtime`, без аудио, транскриптов и токена. Сам звук произнесённого wake word до его BLE-доставки этими логами не измеряется.
4. Установить новую версию; выполнить тот же протокол, сохранить `after.log`. `python3 scripts/voice-timing-summary.py before.log > before.json` и аналогично для after. Не смешивать перезагрузки телефона/несколько процессов в одном логе. Capture=0 бывает у cloud/raw; группировка идёт по capture_requested, а не только id.
5. Сравнить отдельно холодный вызов и тёплые повторы: wake→request, request→first_packet, wake→first_packet, recognizer_start→ready, decoder_start→ready, enable_start→return и enable_start→first_packet. Первый пакет может прийти до подтверждения enable. Проверить, что повторные сессии не создают native recognizer заново (низкое prepare_ms).

| Метрика на телефоне + G2 | До | После |
| --- | --- | --- |
| Холодный wake→first_packet | не измерено | не измерено |
| Тёплый wake→first_packet, median/p95 | не измерено | не измерено |
| Подготовка STT, cold / warm | не измерено | не измерено |
| Рост native memory после 50 сессий | не измерено | не измерено |

## Матрица ручной проверки

* WS по прежнему Tailscale IP: подключение, hello token, запрос/ответ, proactive MCP, переподключение. WSS через Nginx: те же действия, порт 443 и пользовательский 9443, перезапуск Nginx, истёкший/self-signed сертификат, неверное имя и неполная цепочка. При отказе TLS не должно быть обращений к WS/8790. Неверный token не должен авторизоваться или появляться в URL/логах. Проверить настройки после перезапуска.
* 20 последовательных голосовых сессий, смена Moonshine → English Whisper → multilingual RU → EN → Auto; смена настроек во время завершающего decode. Прервать во время cold load, убрать Bluetooth, восстановить связь, повторить. Первый пакет сохраняется до STT; очередь ограничена 400 пакетами (~20 s G2). Переполнение явно отменяет обработку команды. Декодер остаётся посессионным, recognizer переиспользуется; активный lease не освобождается из memory callback.
* Для освобождения на фоне/нехватке памяти: `adb shell am send-trim-memory com.faceclaw.app RUNNING_LOW`; повторить idle и во время decode. Через Android Studio Memory Profiler проверить native heap и отсутствие монотонного роста. Close откладывает освобождение до возврата активного lease. При убийстве процесса ресурсы освобождает ОС.
* Русские команды, не менее 5 повторов каждой: «поставь таймер на пять минут», «открой настройки», «покажи погоду в Екатеринбурге», «напомни купить молоко завтра», «отправь сообщение в Telegram», «открой GitHub и найди Faceclaw», «создай pull request для OpenClaw». Для EN: “set a timer for five minutes”, “open settings”. Проверить RU и Auto, шум/тишину, разные темпы, речь сразу после wake. Оценивать совпадение намерения/чисел/имён и WER по вручную подготовленному эталону; сами тексты хранить отдельно от диагностических логов.
* Многоязычный base выбран как начальный компромисс размера и скорости в текущем runtime. Качество смешанной речи и G2 пока не подтверждено. Если device-корпус не проходит, сравнить multilingual small int8 (тот же sherpa, больше память/время) и GigaAM v2/v3 (есть экспорты под sherpa, лучше ориентирован на RU, но не замена EN/Auto). Новый runtime сейчас не нужен.

## Сборка, установка, откат

Нужны Node/npm, NativeScript CLI 9, JDK 17/21, Android SDK platform/build-tools 35, Android NDK и SDK CMake; актуальные версии проекта заданы в Gradle. Скопировать `build_paths.sh.template` в `build_paths.sh`, задать JAVA_HOME/ANDROID_HOME/PATH. Затем:

```sh
npm ci
npm test
npm run test:kotlin
npx tsc --noEmit
./build.sh
adb install -r platforms/android/app/build/outputs/apk/debug/app-debug.apk
```

Первый build скачивает sherpa, liblc3 и llama.cpp и собирает JNI arm64. Для release использовать существующий signing workflow репозитория; debug APK нельзя установить поверх APK с другой подписью. Перед заменой экспортировать настройки штатным способом, сохранить старый подписанный APK. Откат: установить прежний APK с той же подписью (`adb install -r -d old.apk`, если Android разрешает downgrade); при запрете понизить версию через собственную сборку со старым кодом и актуальным versionCode. Удаление приложения стирает данные, поэтому сначала сохранить настройки. Дополнительные ключи схемы/языка старая версия игнорирует; прежние ключи WS/token/provider не переименованы. После отката при необходимости выбрать прежний voice provider; скачанный multilingual каталог не используется старой версией.
